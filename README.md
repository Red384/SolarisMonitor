SolarisMonitor — Surveillance simplifiée des relais Tor

SolarisMonitor est un outil de surveillance conçu pour faciliter le suivi des relais du réseau Tor. Développé en Python, ce logiciel se présente comme une alternative à Nyx, avec pour objectif de proposer une solution simple, rapide et pratique pour surveiller le fonctionnement des relais Tor.

🔧 Caractéristiques principales

Surveillance des relais Tor : un outil dédié au suivi des relais du réseau Tor.

Alternative à Nyx : une autre approche pour surveiller son environnement Tor.

Configuration simplifiée : le logiciel vise à fonctionner sans nécessiter de modification du fichier de configuration torrc.

Connexion configurable : si le port de contrôle Tor n'est pas détecté automatiquement, il est possible de le spécifier manuellement.

Développement en Python : un programme conçu pour être exécuté dans un environnement Python compatible.

🚀 Installation et utilisation

Lorsque le port de contrôle Tor n'est pas détecté automatiquement, il est possible de lancer le programme en précisant le port souhaité :

python3 solaris-monitor1.py --port 9001

Le port 9001 est donné à titre d'exemple et doit être remplacé par celui configuré dans ton installation Tor.

🎯 Objectif du projet

SolarisMonitor a pour ambition de rendre la surveillance des relais Tor plus accessible, en privilégiant la simplicité d'utilisation et une configuration minimale.
